# 激光晶体温度场测量
## 文献解读与实验方案

编制日期：2026 年 10 月 5 日　｜　依据：课程 PPT 导出 PDF 第 62–66 页及三份参考文献

**建议课题名称：基于 Er³⁺ 双绿光荧光强度比的泵浦激光晶体温度剖面测量及共聚焦扩展。**

实验的核心是让晶体中的 Er³⁺ 离子充当光学温度探针。先在已知温度下标定 520 nm 与 540 nm 荧光带的积分强度比，再在固定泵浦和散热条件下扫描荧光信号，把各位置的比值换算成温度。

建议把课题分成两个阶段。第一阶段完成可靠标定、沿泵浦方向的一维有效温度剖面、功率与散热对照及热传导模型。第二阶段增加独立弱探测光与共聚焦空间选择，验证局部温度测量和二维分布。三维测量以轴向响应和信号质量验证通过为前提。

### 本方案的适用条件

目前材料中没有实际器材清单或样品参数。本方案按文献中的 **Er/Yb 共掺透明激光晶体，优先 Er:Yb:LuAl₃(BO₃)₄（LuAB）**设计。实际宿主、掺杂、切向、镀膜与尺寸必须在装置搭建前确认。

如果实际样品只有 Yb³⁺ 或 Nd³⁺，没有合适的 Er³⁺ 双绿光信号，则不能照搬这套 FIR 温度计，应先选择该样品可标定的光谱或寿命测温方法。不得为了套用公式任意假定掺杂。

### 最终需要交出的结果

- 实际样品的 FIR–温度标定曲线、拟合参数、有效温区及独立验证误差。
- 至少三档泵浦功率的温度剖面，以及两种散热条件下的对照。
- 最高有效温度、峰值位置、温升随吸收泵浦功率的关系和重复性。
- 明确几何、热源、边界条件的模型，并比较模型与实验的偏差。
- 若完成共聚焦扩展，附上空间响应、探测光扰动及背景串扰的验证。

**所有“建议参数”均为起步设计值，不是已经达到的实验性能。** 文献数值标为 [R1]、[R2]、[R3]；课程材料标为 [S]。页码均采用 PDF 页码。

# 1　测量原理：为什么荧光能读出温度

### 泵浦为什么会加热晶体

晶体吸收近红外泵浦光。吸收能量的一部分以激光或荧光离开晶体，另一部分通过非辐射过程等转化为热。局部热源与散热条件共同决定温度分布。温度梯度会改变折射率并产生热应力，影响激光模式、效率和稳定性。[R1，第 1 页]

976 nm 泵浦与 1550 nm 激光之间的波长差对应约 37% 的理想量子亏损，但实际热负载还取决于能量提取、非辐射损失和再吸收，不能把 37% 直接当作所有工况的发热比例。

### Er³⁺ 的两条绿光带

Yb³⁺ 吸收约 976/980 nm 光并向 Er³⁺ 传能，经上转换产生绿光。Er³⁺ 的两个热耦合能级分别发出约 520 nm 与 540 nm 荧光：

- 520 nm：²H₁₁/₂ → ⁴I₁₅/₂。
- 540 nm：⁴S₃/₂ → ⁴I₁₅/₂。

在热耦合成立且其他影响受控时，温度升高使较高能级的相对布居增加，因此比值 R = I₅₂₀ / I₅₄₀ 增大。这里的 I 是整个荧光带的积分面积，不是峰顶的单个数值。[S，第 64 页；R1，第 1–2 页]

```text
R(T) = A exp(-B/T)                 B = ΔE/kB
ln R = ln A - B/T
T = B / ln(A/R)                   T 的单位为 K
```

温度比值能消除部分共同强度变化，例如整体收集效率和激发强度的共同缩放。但波长响应、偏振选择、自吸收、背景及非热平衡可能改变比值，需要实测检查。

### 文献中的数值应如何理解

[R1，第 2 页] 对其样品给出 R = 8.67 exp(-1083.6/T)。代入 300 K 与 400 K，R 约为 0.234 与 0.577，说明升温后 520 nm 带相对更强。**8.67 和 1083.6 K 仅作示例，本实验必须重新拟合。**

相对灵敏度 Sr = (1/R)(dR/dT) = B/T²。只考虑比值噪声时，uT ≈ (T²/B)(uR/R)。用文献 B 举例，1% 比值波动在 300 K 对应约 0.83 K，在 400 K 对应约 1.48 K；这不包含标定、位置和温度梯度误差。

### 2017 年实验的可借鉴条件

[R1，第 2–3 页] 使用 5 × 5 × 0.7 mm³ 的 c 切 LuAB 晶体，Er 与 Yb 掺杂分别为 1.1 at.%、24.1 at.%。恒温标定覆盖 300–540 K。工作泵浦为 976 nm，束腰直径约 100 μm；从侧面收集绿光并将晶体像耦合到 100 μm 光纤。

其沿泵浦轴扫描间隔为 70 μm。这个数值是采样步距；光纤除以 1.4 倍放大率得到约 71 μm 物方口径，也仍不是经过 PSF 验证的光学分辨率。论文未给单点积分时间或整幅更新时间。

文中报告的高温结果超过了 540 K 标定上限。自己的实验应在有效温区内工作，或先扩展标定。论文的 ±12 K 不能作为本装置精度保证。

### 2024 年论文的主要启发

[R2，第 2–6 页] 用 5 × 5 × 0.74 mm³ 晶体、蓝宝石和水冷铜架研究温度剖面。三束模型同时考虑入射泵浦、反射残余泵浦和腔内 1.55 μm 光的再吸收，使温度曲线相对残差降至约 0.96%。这描述的是模型与实验曲线的吻合程度。

不同散热边界会使峰温出现在晶体内部，并导致剖面不对称。因此本实验应测量峰值位置，不能预设最高温必定在入射端，也不能把任何非对称都归因于对准错误。

### 课程 PPT 的技术路线应怎样落地

PPT 第 65 页是侧面荧光探测，第 66 页提出激光点扫描加共聚焦针孔。完整共聚焦需要点激发与点探测配合。只对工作泵浦产生的体荧光加检测针孔，得到的是空间加权信号，深度选择性必须验证。[R3，第 4–5、8–10 页]

# 3　基础装置与坐标定义

### 先搭建可验证的一维测量装置

定义 z 为主泵浦传播方向，z = 0 为入射端；x 为观察侧面内的横向坐标；y 为从观察侧面向晶体内部的深度。晶体、主泵浦及散热夹具固定，扫描检测端的位置。

```text
976/980 nm LD → 功率调节/快门 → 聚焦透镜 → 固定晶体 → 泵浦光束终端
                                         ↓ 侧向绿光
                 成像透镜 → 泵浦阻挡滤光片 → 像面光纤/孔径 → 光谱仪

恒温台/散热座 + 温度传感器 → 温度记录
功率计 + 位移台坐标 + 光谱仪 → 计算机同步记录
```

起步时不要求产生 1.55 μm 激光振荡。先研究“泵浦工作下的激光晶体温场”，完成测量链路后，再增加谐振腔研究激光提取对热负载的影响。两种状态在数据中分别标记。

| 部件 | 建议配置或验收依据 |
| --- | --- |
| 样品 | 有可辨识 520/540 nm 双带的 Er/Yb 晶体；确认镀膜和可观察面 |
| 主泵浦 | 稳定连续 976 或 980 nm LD；波长与实际吸收匹配，可从低功率起步 |
| 光束控制 | 恒流驱动、快门、衰减器、准直/聚焦镜、光束终端和固定支架 |
| 温控与参考温度 | 恒温台或加热铜座、贴近样品的标定传感器；目标稳定性 ≤0.2 K |
| 初级检测 | 成像透镜、可移动 50–100 μm 光纤或孔径、二维微调台 |
| 光谱仪 | 覆盖至少 510–570 nm；约 1 nm 或更好分辨率，线性且能导出原始光谱 |
| 滤光 | 通过两条绿光带，充分阻挡 976/980 nm；有腔时也阻挡 1550 nm |
| 功率测量 | 波长和量程适配的功率计，记录晶体前泵浦及透射/反射泵浦 |
| 散热夹具 | 保留观察窗，记录接触面、导热层、夹紧方式和冷却温度 |

滤光是否足够，以实际漏光、光谱仪饱和和检测器损伤阈值验收，不只看名义波段。先挡住所有激光、采暗谱，再以最低可用功率调光路。

# 4　标定实验：把荧光变成温度计

### 标定操作

1. 用最终检测光路、同一光谱仪、同一偏振与滤光配置完成标定。选定积分区间后保持不变。
2. 把晶体与恒温座良好接触。参考传感器放在靠近样品的位置，必要时加第二支传感器检查温度均匀性。控制器显示值只作辅助记录。
3. 用低功率、宽光斑激发，尽量使标定区温度均匀。比较两个低激发功率下的 R，检验激发自身加热或功率依赖。低功率一致性还不足以证明强泵浦适用，后续须在已知局部温度条件下检查预计工作功率密度范围的 R(T,I) 依赖；无法验证时限制工作强度或建立强度相关标定。
4. 建议起步温区为 298–423 K（约 25–150 ℃），每 10–15 K 一个点；材料、镀膜、胶和夹具允许温区需先确认。若实际装置不能达到此范围，就缩小实验工作温区。
5. 建议热平衡判据：参考温度连续 3 分钟漂移 ≤0.2 K；同时不同测点比值不呈持续变化。此为起步判据，后续按实际稳定性调整。
6. 每个温度点至少采 5 条重复光谱和相应暗谱。再作降温标定，检查滞后和漂移。
7. 对净光谱积分，拟合 ln R = a + b/T，得到 A = exp(a)、B = -b。对异方差数据使用加权拟合，保存参数协方差与残差。
8. 留出至少 3 个中间温度点，不参与拟合，用于独立验证反演误差。检验盲点和升降温一致性后，才用于泵浦温场。

### 积分区间如何选

先在 510–570 nm 范围查看实际光谱，以两带间的谷值确定分界，并覆盖主要发射带。可用 A = 510–530 nm、B = 533–560 nm 作为查看光谱的起始候选，但必须依据实际谱线和背景修改；这不是文献给定端点。

固定窗口后重新拟合，不能在每条谱上随意移动窗口。检查窗口边界小幅改变时的温度敏感性，排除背景、带重叠和截掉谱线的影响。采用峰高比时须另行标定。

### 标定的建议验收门槛

工作温区内 R 单调，独立验证点误差目标 ≤2 K；升降温差异及改变弱激发功率后的温差均不超过已评估的不确定度。再验证标定可迁移的工作功率密度范围，避免把激发非热效应当升温。该数值是项目目标，不是预先保证。若达不到，则改善信噪比或缩小适用条件后重新验证。

**标定上限同时是首轮温场测量的温度上限。超过上限的值记录为“未验证外推”，暂停升功率并先扩展标定。**

# 5　一维温度剖面：实际测量步骤

### 装调与首轮测量

1. 固定晶体和夹具，以相机或显微观察确认入射端、出射端与泵浦发光区域。记录样品朝向和 z = 0。
2. 用标尺或已知尺寸结构标定侧面成像倍率 M，并验证移动像面光纤时物方坐标的换算：Δz = Δz_image/M。光纤接收口径投影为 d_fiber/M，仅作几何估算。
3. 建议首轮主泵浦光斑直径 0.2–0.3 mm，以便降低峰值功率密度并获得信号。用相机或刀口法测量并写明直径是 1/e²、FWHM 还是其他定义。
4. 从能取得双带信号的最低功率起步。先在固定位置观察升温轨迹，确定稳定时间和温度是否在标定范围内。
5. 在同一焦面沿 z 扫描。若厚度约 0.7 mm，可先采用 50 μm 物方步距，约 15 个位置；根据实测空间响应再决定是否细化。边界混合体素单独标注。
6. 每个位置采暗/背景与光谱，记录时间戳、功率、冷却温度和坐标。按预先制定的双带信噪比阈值剔除无效点。
7. 扫描前后回到同一参考点。若温差超出不确定度，检查泵浦漂移或热平衡，重测该剖面。
8. 同一工况至少重复 3 条剖面；可作正反向扫描，检验方向依赖。改变功率后重新等待稳态。

### 首轮功率安排

可从约 0.05 W 开始，依次试 0.1、0.2、0.4、0.6 W 的晶体前入射泵浦功率。仅在样品、泵浦器与温控允许且温度未超出标定范围时继续。弱信号时可增加积分时间或调整光斑，不能为追求亮度直接跳到文献的 5 W 工况。

### 结果应如何命名

第一阶段结果称为 **“指定观察几何下、沿泵浦轴的荧光加权有效温度剖面”**。若收集体积内存在明显温度梯度，测得 R 是两带信号各自积分后的比值，反演温度一般不等于温度的简单平均，更不能自动等同于理想点温度。

点扫描只在温场足够稳定时代表同一工况。整条剖面的更新时间等于所有点的积分与移动时间之和，应实测报告；不能仅因激光在运行就宣称具有快速整幅实时成像。

# 6　共聚焦扩展：两种架构要分清

### A. 检测端加针孔：适合先比较空间混合

将初级透镜换成长工作距离物镜和匹配管镜，在正确像面设置可调针孔，再耦合光谱仪。晶体和主泵浦固定，移动检测坐标；针孔与孔后的光纤输入整体移动，或通过稳定中继保证耦合不随位置变化。调焦时物镜沿观察光轴平移。

它可以改变局域发光点的检测权重，但对横向广泛的体荧光，仅靠针孔不保证清晰的光学切片。先比较同一泵浦剖面在不同针孔下的峰值、宽度和信噪比，称为“空间筛选对照”；只有轴向响应与焦外串扰验证通过，才能报告有限深度选择性。

无主泵浦发光的区域没有可用 FIR 信号。不得用插值把这些区域填成完整的晶体体温场。

### B. 点激发与点探测：完整共聚焦扩展

固定主泵浦作为热源，另设独立弱探测光，经二向色镜与物镜聚焦到测量点。初步可尝试弱 980 nm 探针，但激发强度能否获得信号且不扰动温度须实测。点扫描只移动探测焦点，主泵浦和样品不动。

```text
固定主泵浦 → 固定晶体与固定散热边界
弱探针 → 扫描/定位 → 二向色镜 → 物镜 → 同一晶体的局部测量点
绿光回收 → 二向色镜 → 阻挡滤光 → 管镜 → 共焦针孔 → 光谱仪
```

工作泵浦本身也产生绿光，两者荧光不能仅靠滤色片区分。建议试探针开/关成对采谱：保持主泵浦不变，计算差分谱 ΔIλ = Iλ,on - Iλ,off。必要时采用调制探针和同步双通道检测。

差分比值 ΔI₅₂₀/ΔI₅₄₀ 需要独立标定，且必须验证：探针不引起可辨识升温；差分两带信号均足够；激发非线性、主泵浦强度及漂移不破坏标定。差分谱不是未经验证即可使用的局域温度真值。条件不足时停留在第一阶段。

### 采购与搭建时的几何问题

5 × 5 × 0.7 mm³ 薄片若从侧面观察，中心泵浦距侧面可能达 2.5 mm。高折射率界面、球差和仅 0.7 mm 高的侧面会限制可达性。先用实际样品验证焦点、截光和 PSF，再选物镜；单靠工作距离不能保证内部性能。

0.7 mm 厚片中心距观察侧面 2.5 mm 时，厚度方向直达收集内锥半角约受限于 arctan(0.35/2.5) ≈ 8°。需分别验证厚度与面内方向的分辨率，并检查内反射背景。

可比较长工作距离中等 NA 侧视与端面检测；端视改变了测量坐标及加权方向，不再是同一侧视轴向剖面。若改为近侧面泵浦，须记录实际泵浦位置并更新散热几何。

# 7　空间分辨率与采样：怎样证明测到哪里

### 针孔的起步尺寸

以荧光波长约 530 nm、实际检测总倍率 M 和物镜 NA 估算一 Airy unit 的像面孔径：

```text
d_AU ≈ 1.22 λ_em M / NA
例：λ_em = 0.53 μm，M = 20，NA = 0.40，d_AU ≈ 32 μm
```

可比较约 0.5、1、2 AU。孔径越小通常越少接收焦外信号，也会减少光子数并增加测温噪声。选择依据应是温度误差与空间混合的共同表现，而不是最小孔径。两波段始终使用同一针孔配置标定。

### 实测空间响应

1. 用尺寸已知的点状/薄层荧光参照，测横向与观察光轴方向的响应；参照发射应覆盖接近两条绿光带的波长。
2. 表面测试只能证明表面性能。深部测试需加入实际晶体或近似等效折射率与厚度的透明层，评估深度引起的球差与焦外串扰。参照本身尺寸应从响应中考虑或给出上限。
3. 记录不同深度、针孔和两波段的横向/轴向 FWHM。仅从实际厚度已知的发光边缘得到的曲线，应标作边缘响应，避免冒充点 PSF。
4. 完整共聚焦中，联合点激发与点探测形成采样权重；检测端针孔架构须另外测扩展发光层的焦外响应、评估整个泵浦发光体的混合。点源 PSF 良好本身不能证明扩展体源的切片能力，不能用理想共焦公式代替实测。
5. 将步距选为实测 FWHM 的约一半或更小以进行适当采样。扫描步距只描述采样密度，不表示分辨率。

### 深度与色差校正

观察光轴方向的机械位移不一定等于晶体内部焦点位移。低 NA、平面界面的近轴近似可给出 d_true ≈ (n_sample/n_air)d_nominal，但高 NA、双折射、厚样品下要通过已知厚度或实际界面验证。不得把近轴倍率直接当精确校正。

检查 520 与 540 nm 是否采样同一位置。存在色差时，两带可能来自不同体积，在强温度梯度下使 R 产生伪温差。控制两带共焦位置、相同收集设置，并用均温样品验证。

**建议阶段目标：优先做到对 50–100 μm 尺度的温场结构具有可验证的分辨能力，再根据实测信噪比决定能否提高。任何亚微米或数微米性能都必须另行证明。**

| --- | --- | --- | --- |
| 恒温标定 | 参考温度 | 弱激发、收集光路、积分窗口 | R(T)、有效温区、独立验证误差 |

每种关键工况至少重复 3 次；如果时间有限，先做完整标定、三档泵浦和两档散热，再扩展光斑和共聚焦。不要一次改变多个参数。

### 三个必须做的对照

**均温对照：** 在恒温、弱激发条件下扫描晶体，确认同温区各位置的 FIR 是否一致。若存在位置依赖，检查掺杂、厚度、自吸收、镀膜或收集角，并考虑分位置标定。

**漂移对照：** 每幅扫描前后回到同一位置，同时记录泵浦功率和冷却温度。固定点变化超过不确定度时，不把时间漂移解释为空间梯度。

**空间混合对照：** 改变接收口径或针孔，比较峰温和剖面宽度。口径依赖可揭示有限采样体积影响，但“针孔变小后峰温更高”本身还不能证明该峰温等于局域真值。

### 有谐振腔后可研究的问题

在相同吸收泵浦与冷却条件下比较起振和未起振状态，同步测 1.55 μm 输出。输出变化会改变能量提取，也可能改变模式、再吸收和热源，所以要同时记录光斑与运行状态。禁止假定出光越强在所有材料和腔条件下都必然越冷。

先做固定点开泵升温，再决定二维图能否表示同一时刻。基础架构关泵后不能持续读出 FIR；冷却曲线需独立弱探针并验证扰动。若整幅采集期间温场显著变化，采用稳态映射，或升级为同步双波段成像并校正像素响应和配准。

# 9　数据处理与不确定度

### 从原始光谱到温度

保留原始光谱，不只保存处理后的温度。处理顺序为：暗谱与背景校正、响应/线性检查、两带积分、FIR 与不确定度、有效范围检查、温度反演、坐标换算、重复性统计。

```text
Jλ = (Cλ - Dλ - 背景λ) / Hλ
I_A = 积分_A Jλ dλ       I_B = 积分_B Jλ dλ
R = I_A / I_B
T_eff = B / ln(A/R)      T_℃ = T_eff - 273.15
```

Hλ 为经验证的响应修正；若没有绝对响应标定，可在同一检测系统、设置和稳定响应下直接标定净计数比。不得套用另一台仪器的 A。改变滤光片、光纤、针孔、偏振或光谱仪后，要验证标定迁移，必要时重标定。

负积分、饱和、任一带低信噪比或超温区的数据应标无效。建议先用两带积分 SNR ≥30 作为初步筛选，再由目标 uT 推导实际阈值；弱通道往往决定测温质量。

| 不确定度来源 | 评估方法 |
| --- | --- |
| 参考温度与样品均匀性 | 传感器校准信息、两个测点对照、等待时间检验 |
| 光谱噪声、背景和积分窗口 | 重复光谱、暗谱、背景区域、窗口扰动 |
| 标定模型及参数 | 留出点误差、拟合残差和参数协方差 |
| 坐标与有限接收体积 | 倍率/位移校准、PSF、口径对照、边界混合 |
| 光路/功率漂移 | 扫描前后参考点、同步泵浦和冷却记录 |
| 探针扰动与差分误差 | 不同探针功率/占空比、开关背景、独立差分标定 |

独立噪声近似下，(uR/R)² ≈ (uIA/IA)² + (uIB/IB)²；存在共同背景或相关波动时需加入协方差项。对拟合参数与 R 联合传播，推荐使用包含参数协方差的蒙特卡洛计算反演区间。

只用温度重复标准差不能表示总准确度。对可量化的随机和校准项合成不确定度；对尚未解决的空间混合、色差或高温外推单独给出偏差/限制，不随意塞入一个小误差条。

标定曲线及残差；各功率 T_eff(z) 并带误差/有效域；ΔT_max 对 P_abs；散热对照；实测空间响应；模型与实验残差。二维图中掩膜显示低信号区域，插值图同时给出原始测点。

# 10　热传导模型与实验比较

### 先用与基础实验一致的模型

```text
瞬态：ρ Cp ∂T/∂t = ∇·(K ∇T) + Q
稳态：∇·(K ∇T) + Q = 0
```

K 为导热系数或各向异性导热张量。用实际晶体尺寸、泵浦位置及夹具建模。只在光束和边界近似轴对称时采用轴对称简化；靠近侧面泵浦或不对称装夹通常需要三维模型。

主泵浦单束的起步热源可写为 Q = ξ_abs α I(r,z)。其中 ξ_abs 是“吸收泵浦中转化为热的比例”，I 用晶体内部传播的光强；若光束包络变化，应使用实测包络或适合实际光束的传播模型。

对于横向未截断、无额外反射的高斯束，I = [2P_entry/(πw²(z))] exp[-2r²/w²(z)] exp(-αz)，w 为 1/e² 半径，P_entry 是进入晶体的泵浦功率。核验 ∫Q dV = ξ_abs P_abs；不要重复乘或除吸收率。

实验上用晶体前入射泵浦功率减去透射、反射及可测散射的泵浦功率估计 P_abs，测量须选择泵浦波段。若无法完整计量，注明吸收功率估计的不确定度。也可使用归一化热源形状，使总体热功率明确等于 ξ_abs P_abs。

### 必须体现的边界

- 散热接触面：可用实测散热座温度和接触换热系数 hc，热通量为 hc(T - T_sink)。理想恒温边界仅作近似。
- 暴露表面：对流边界 h(T - T_air)，h 不宜任意取值后声称材料热参数已被测定。
- 高温工况：按需要加入辐射、温度依赖材料参数，并验证其对结果是否有影响。

[R2，第 3 页] 给出的 LuAB 初始参数为 k = 4.7 W/(m·K)、ρ = 3840 kg/m³、Cp = 660 J/(kg·K)，可作为同类材料的敏感性分析起点。它们不代表本样品的实测参数，也不能移植到另一宿主；稳态计算不依赖 ρCp，瞬态才需要。

### 怎样比较才公平

模型优先预测有限接收体积内两带荧光信号并计算同样的 R 和 T_eff，再与实验比较。存在强梯度时，不直接把理想中心点温度与荧光加权温度当作同一量。至少测量峰值、峰位置、宽度和两端差异。

ξ_abs、k 和接触热阻可能共同影响峰温。先固定独立测得的参数，再拟合少数未知量；一条曲线不能唯一确定三者。无腔也可能存在界面/下游反射，按实测贡献决定返程泵浦热源；起振后再考虑腔内激光再吸收。[R2，第 4–6 页]

### 向导师说明方案时的重点

**测量量是什么？** 两个热耦合 Er³⁺ 能级发射的荧光带积分强度比，经同一实际样品和光路标定后反演温度。

**为什么先做一维？** 先验证温度反演、坐标和稳定性，可在课程中期前获得可重复数据，再提高空间选择性。

**共聚焦解决什么？** 尽量减少焦外与邻近位置的荧光混合，但需要点激发、点探测和实际深度响应验证。针孔与扫描步距本身不能证明局域温度分辨率。

**主要研究问题是什么？** 泵浦功率、光斑和散热边界如何改变温升及峰温位置；有限收集体积如何影响温度读数；哪些模型假设能解释实测剖面。

**什么是最合适的创新点？** 先以可量化的标定和空间混合对照建立可靠测量，再在主泵浦固定条件下实现经验证的弱探针共聚焦测温，或定量研究实际夹具的散热边界。

### 搭建前需确认的四项信息

实际晶体参数及可观察面；可用泵浦器/光谱仪/温控/位移台；夹具与样品允许温区；课题是否要求激光振荡运行。这些信息决定最终器材规格与功率上限，但不影响先按本方案开展绿光验证与标定设计。
